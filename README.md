# game-libary-for-your-pc
game libary for your pc
✨ Özellikler
• Hafif ve Hızlı Yapı: Python'ın yerleşik Tkinter arayüzü ile çalışır; sistemi yormadan anında açılır. (JPG, WebP vb. tüm kapak formatları için yalnızca isteğe bağlı pillow kütüphanesi yeterlidir.)
• Geniş Başlatma Desteği: Bilgisayarınızdaki .exe, .bat, .cmd, .lnk, .html dosyalarını veya doğrudan web oyunu bağlantılarını (http://, https://) ekleyip çalıştırabilirsiniz.
• Özelleştirilebilir Kapak Görselleri: Oyunlarınıza özel kapak resimleri ekleyebilirsiniz. Kapak seçilmediğinde uygulama, oyunun baş harfine ve adına özel renkli bir kapak kartı otomatik oluşturur.
• Oynama İstatistikleri ve Arama: Her oyunun kaç kez oynandığını takip eder, üstteki arama çubuğu ile kütüphanenizdeki oyunları anında filtrelemenizi sağlar.
• Duyarlı (Responsive) Izgara Arayüzü: Pencere boyutunu değiştirdiğinizde oyun kartları ekrana otomatik olarak yeniden dizilir.
🚀 Nasıl Kurulur ve Çalıştırılır?
1. Gereksinimler
• Bilgisayarınızda Python 3 kurulu olmalıdır.
• Tüm resim formatlarını (JPG, WebP, BMP vb.) kapak olarak kullanabilmek için terminale pip install pillow yazarak Pillow kütüphanesini kurmanız önerilir (kurulmazsa yalnızca PNG ve GIF kapaklar desteklenir).
2. Başlatma
• oyun_kutuphanesi.py dosyasını bilgisayarınıza indirin.
• Dosyaya çift tıklayın veya terminal/CMD üzerinden python oyun_kutuphanesi.py komutunu çalıştırın.
• Açılan koyu temalı modern pencerede sağ üstteki "+ Oyun Ekle" butonuna tıklayarak ilk oyununuzu ekleyin.
🖥️ Arayüz Kullanımı
• + Oyun Ekle: Yeni bir oyun dosyası veya web bağlantısı ile kapak görseli eklemenizi sağlar.
• Ara: Kütüphanenizdeki oyunlar arasında isme göre anında arama yapar.
• ▶ Oyna (veya Kapağa Çift Tıklama): Oyunu kendi ana klasörü üzerinden sorunsuz şekilde başlatır ve oynanma sayacını artırır.
• Düzenle / Sil: Oyunun adını, dosya yolunu veya kapağını güncellemenizi ya da kütüphaneden kaldırmanızı sağlar.
⚠️ Bilinen Notlar
• Eklediğiniz oyunların listesi ve kapak görselleri otomatik olarak kullanıcı klasörünüzdeki OyunKutuphanesi dizinine (oyunlar.json ve kapaklar klasörü) kaydedilir.
• Kütüphaneden bir oyunu Sil dediğinizde yalnızca listeden ve kapak arşivinden kaldırılır; oyunun bilgisayardaki gerçek dosyaları silinmez.
• Uygulama Windows, macOS ve Linux işletim sistemleriyle uyumludur.


✨ Features
• Lightweight & Fast Architecture: Built with Python's native Tkinter GUI; launches instantly without draining system resources. (Only the optional pillow library is needed to support all cover image formats like JPG and WebP.)
• Broad Launch Support: Add and run local .exe, .bat, .cmd, .lnk, and .html files, or direct web game URLs (http://, https://).
• Customizable Cover Art: Assign custom cover images to your games. If no cover is selected, the app automatically generates a color-coded placeholder card featuring the game's initial letter.
• Play Tracking & Instant Search: Automatically tracks how many times each game has been played and lets you filter your library in real time via the top search bar.
• Responsive Grid Layout: Game cards dynamically rearrange themselves to fit the window whenever you resize the application.
🚀 How to Install & Run
1. Requirements
• Python 3 must be installed on your computer.
• To use all image formats (JPG, WebP, BMP, etc.) as covers, installing Pillow via pip install pillow is recommended (without it, only PNG and GIF covers are supported).
2. Launching
• Download the oyun_kutuphanesi.py file to your computer.
• Double-click the file or run python oyun_kutuphanesi.py in your terminal/CMD.
• In the dark-themed main window, click "+ Oyun Ekle" (+ Add Game) in the top-right corner to add your first game.
🖥️ Interface Usage
• + Oyun Ekle (+ Add Game): Lets you add a new game file or web link along with a cover image.
• Ara (Search): Instantly filters games in your library by name.
• ▶ Oyna (Play / Double-Click Cover): Launches the game directly from its native working directory and increments the play counter.
• Düzenle / Sil (Edit / Delete): Allows you to update the game's title, file path, or cover art, or remove it from the library.
⚠️ Known Notes
• Your game list and resized cover images are automatically saved inside the OyunKutuphanesi folder in your user home directory (oyunlar.json and the kapaklar folder).
• Clicking Sil (Delete) only removes the entry and cached cover from the launcher; your actual game files on disk remain untouched.
• Compatible with Windows, macOS, and Linux operating systems.
